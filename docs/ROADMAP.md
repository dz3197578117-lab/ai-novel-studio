## 分阶段计划

### 阶段 0：地基（已完成）
TypeScript 全栈 monorepo、SQLite 存储、OpenAI 兼容接入、流式生成、多模型配置、自动备份。

### 阶段 1：一致性引擎 ✅ 本轮
- **伏笔台账**：埋在哪章、计划何时回收、是否已回收；未回收的伏笔会**自动注入生成上下文**
- **时间线**：故事内时间 + 对应章节，按章排序
- **一致性检查**：把设定 / 伏笔 / 时间线 / 最近章节交给模型，产出可操作的问题清单

### 阶段 2：锁定与分层创作
- **锁定**：人物设定、关键情节、已定稿段落标记为锁定，生成时不得改动（提示词 + 后置校验）
- 创作链路补中间层：脑暴 → 大纲 → **细纲** → **场景卡** → 成稿
- 新增改造模式：缩写、改视角（第一/第三人称）、改节奏（快/慢）

### 阶段 3：版本与协作
- 章节版本树 + diff + 回滚（当前只有整库备份）
- 分支写作（实验性改写不影响主稿）

### 阶段 4：知识库与素材
- 上传设定集 / 参考文档 / 风格样本，切分入库
- 引用溯源：生成时标注哪段来自作者设定、哪段是模型发挥
- 标签 + 检索 + 关联

### 阶段 5：质量与成本
- 生成质量评分（可解释的分项打分）
- 用量与成本统计、失败重试可视化、多模型自动降级
- 去 AI 味检查器（套话、排比、空洞抒情识别）

### 阶段 6：体验与底线
- **移动端响应式**（当前手机不可用，属于必须补的短板）
- PDF / EPUB 导出
- 内容审核开关、商用授权声明

---

## 明确不做的

- **云端多人协作**：本产品定位是本地单人写作工具，账号体系/权限会破坏「数据不出本机」这个核心承诺
- **社区模板市场**：需要服务端生态，与本地定位冲突
- **A/B 测试平台**：单人使用没有统计意义，改为「同一段落生成 2 版供作者选」更实用
